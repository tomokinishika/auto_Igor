# Igor Pro連携 データ自動分類・解析パイプライン

本リポジトリは、測定データ（`.lmf`等）をファイル名から角度ごとに自動分類し、外部解析プログラム（`coinchp.exe`）で一括処理を行った後、三次元運動量データ等の結果をIgor Proへ自動的に読み込ませるためのPythonスクリプトです。

# 動作環境・前提条件

* **OS**: Windows (Igor ProとのCOM通信を利用するため)
* **Python**: Python 3.x
* **必須パッケージ**: `pywin32` (Igor Proとの連携に使用)
* **ソフトウェア**: WaveMetrics Igor Pro

## セットアップ

1. 必要なPythonライブラリをインストールします。
pip install pywin32

2. スクリプトと同じ階層に `coinchp.exe` を配置します。



## ディレクトリ構成

実行前に以下のようなディレクトリ構造を準備してください。

project_root/
│  main.py 
│  input_sorter.py 
│  coinchp.exe 
│
└─ 250724/ (対象のデータフォルダ例)
    250724_s01_090.lmf
    250724_s02_360.lmf
    ...

## 使い方

コマンドプロンプトまたはターミナルを開き、処理したいデータフォルダ名を引数として指定してスクリプトを実行します。

単一のフォルダを処理する場合:
python main.py 260724

複数のフォルダを一括で処理する場合:
python main.py folderA folderB


## 処理のフロー

1. ファイルの収集・分類: 指定されたフォルダ内のファイルを検索し、ファイル名に含まれる「_3桁の数字」またはsorter用の「s2桁_3桁の数字」から角度情報を抽出してグループ化します。


2. インプットファイル生成: 角度グループごとに `inputfile.txt` を自動生成します（Shift-JISエンコーディング）。


3. 解析プログラムの実行: `coinchp.exe` を自動で呼び出し、結果を `momdata.txt` として出力します。


4. Igor Proへの自動ロード:


* 出力された `momdata.txt` のヘッダー行をPythonで読み取ります。
* Igor Pro内に角度ごとのデータフォルダを初期化・作成します。
* データをIgorへロードし、Python側からコマンドを一括送信して各ウェーブ名をヘッダー情報（`px1`, `py1` 等）に強制リネームします。



## 注意事項

* Igor Proがバックグラウンドの非表示モードで起動したり、起動時のダイアログで通信がタイムアウトしたりするのを防ぐため、スクリプト実行前に手動でIgor Proを立ち上げておく（空のExperimentを開いておく）ことを強く推奨します。
